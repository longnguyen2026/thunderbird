## 📋 Tính năng

- ✅ Tự động cài đặt Thunderbird nếu chưa có
- ✅ Hỗ trợ cả IMAP và POP3
- ✅ Cấu hình SSL/TLS tự động
- ✅ Tạo profile riêng cho BizFly
- ✅ Tương thích với Ubuntu/Debian
- ✅ Hỗ trợ cả Snap và Native version
